# CloudVision CW2

CloudVision is a cloud-native image sharing platform developed using Microsoft Azure services.

## Features

- Upload image files
- Store images in Azure Blob Storage
- Save metadata in Azure Cosmos DB
- REST API using Node.js and Express
- Frontend dashboard with image preview
- GitHub version control integration

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Azure Services
- Azure Blob Storage
- Azure Cosmos DB
